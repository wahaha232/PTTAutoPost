# PTT AutoPost 後續功能規劃整合報告

- 日期：2026-10-22
- 基準版本：0.6.2（已推送 GitHub，Release v0.6.2）
- 性質：評估與規劃整合，**尚未實作任何項目**
- 更新：2026-10-22 依使用者決定更正帳密政策描述（第一、五、九節）；最新整合評估以 `ESTIMATE_2026-10-22.md` 為準
- 說明：token 與時間為粗估，基準是前幾輪實際用量（一個中等批次約 5 萬 token、30 到 60 分鐘）；token 計數不等於帳號方案的實際額度。

## 一、結論摘要

1. 13 項新功能加上 PTT Star 的基本功能與編碼支援，合計約 **62 萬至 66 萬 token、12 至 16 小時**，約佔剩餘額度的 4% 到 5%。
2. **多分頁**是最大的重構，也是其他功能的底座，必須排在多種連線方式之前。
3. **SSH 應該做並放進主程式**：PTT 目前可用 WSS，但 WSS 是網頁版的橋接端點，不是對外保證的協定，SSH 是長期退路，也是三個「只有 SSH」站台的唯一連法。
4. **體積**：目前約 56 MB；剔除用不到的 Qt 元件後約 40 MB；改發資料夾版加 LZMA 安裝程式／7z，**下載大小約 28 至 32 MB**。不使用 UPX，不原生重寫。
5. **廣告暫不做，先做贊助按鈕**。
6. 帳密政策**已放寬**（使用者 2026-10-22 決定）：可記住帳號／密碼，以 Windows DPAPI 加密、每站台 opt-in、自動登入預設關閉；尚未實作，詳見 `ESTIMATE_2026-10-22.md` 第 G 組。

## 三、站台清單（PCMan BBSList，使用者已做 TCP 連線測試）

| 類型 | 站台 |
|---|---|
| WSS＋SSH | PTT（ptt.cc）、PTT2（ptt2.cc）；兩者 Telnet 23 皆已關閉 |
| Telnet 23 | 成大夢之大地、清華楓橋驛站、巴哈姆特、紫丁香、新水木清華、臺大未來最舊小棧、華年小集、網際新世界 |
| 只有 SSH 22 | 交大、中山、臺大資管（皆為「BBS 入口待確認」） |

處理方式：
- 內建這 13 筆為預設站台（名稱、位址、協定、埠）。
- 簡體站台（如新水木清華、紫丁香）常為 GBK 編碼，目前終端機只認 Big5，**每個站台需可設定編碼**（約 +3 至 4 萬 token）。
- PTT2 的登入輔助目前不在信任名單（只信任 ws.ptt.cc），需先做一次只讀 probe 確認 ws.ptt2.cc 才能加入。
- 三個只有 SSH 的站台要等 SSH 完成才能實測。
- 另有 81 個舊清單位址目前無法連線，不納入。

## 四、PTT Star 設定頁對照（使用者提供截圖 4 張）

**A. 基本功能，建議納入（約 +15 萬 token）**

| 功能 | token |
|---|---|
| 文字選取、複製、貼上（**目前完全沒有，日常最缺**） | 約 3 至 4 萬 |
| 滑鼠自訂對應表：左鍵、滾輪、左鍵加滾輪、右鍵加滾輪、側鍵、中鍵、右鍵手勢 | 約 5 至 7 萬 |
| 通知時工作列閃爍、播放音效 | 約 1.5 萬 |
| 視覺選項：字型、行距、游標色、護眼、上班模式（Alt+W）、背景圖加透明度 | 約 4 至 5 萬 |

**B. 需要「讀懂畫面」，工作量大（約 +5 至 8 萬 token）**
黑白名單（隱藏某 ID 的標題與推文）、推文合併相同 ID、推文加亮、灰底、自動更新推文。需要把畫面解析成文章列表／推文結構，不同看板版面可能不同。自動更新推文會定時自動送按鍵，與防閒置同類，須先在真實 PTT 驗證，並只在閱讀畫面使用。

**C. 建議暫不做**
- 網頁式文章、圖片疊在畫面上、依段落（引言／本文／簽名檔／推文）分別設定自動開圖：約 15 至 25 萬，等於再做一個 PTT Star；建議只做超連結點擊與圖片連結用瀏覽器開啟。
- 推文 IP 轉地理位置、貼圖自動上傳圖床：資料會送到第三方，與本專案隱私原則衝突，不做。
- 預設瀏覽器、自動更新檢查：不需要。

## 五、SSH 決策

- PTT 並非只能用 SSH：WSS（wss://ws.ptt.cc/bbs）已實測可用。
- 但 WSS 是網頁版（term.ptt.cc）背後的橋接端點，若改版或關閉，SSH 是唯一退路；三個只有 SSH 的站台也需要。→ **SSH 要做，且放進主程式，不做選配擴充包。**
- 據了解 PTT 的 SSH 以 `bbs@ptt.cc` 連線、不需密碼，登入帳密是進入 BBS 畫面後才輸入；SSH 本身不涉及帳密儲存，帳密是否記住依每站台設定（見第一節第 6 點）。

| 做法 | 大小影響 | 優點 | 風險 |
|---|---|---|---|
| A. 內建 SSH 函式庫（paramiko＋cryptography 等） | 約 +15 至 25 MB | 行為可控、跨環境一致 | 體積最大的一項；需背景執行緒接進畫面 |
| B. 呼叫 Windows 內建 ssh.exe（Windows 10 1809 以後） | 約 0 MB | 最省體積 | 需先驗證：管線取代真終端機時的畫面大小、主機金鑰確認、輸入是否正常 |

建議：**先做一次只讀驗證（約 1 萬 token）**：用 ssh.exe 連 bbs@ptt.cc，確認能收到登入畫面、畫面為 80×24、可乾淨斷線，**不送任何資料**。可行就走 B；不可行走 A（下載大小約 45 至 55 MB，LZMA 壓縮後約 35 至 42 MB）。此項待使用者同意後才執行。

## 六、體積分析與發佈

**現況（0.6.2 建置統計）**：未壓縮約 133 MB，其中 PySide6 約 97 MB（73%）；單檔 EXE 約 56 MB。

| 大小 | 檔案 | 用到嗎 |
|---|---|---|
| 20.6 MB | opengl32sw.dll（軟體 OpenGL） | 否 |
| 10.4／9.5／6.5 MB | Qt6Core／Gui／Widgets | 是 |
| 6.9 MB | python312.dll | 是 |
| 6.6／5.3／4.6 MB | Qt6Quick／Qml／Pdf | 否 |
| 5.8＋5.2 MB | libcrypto-3*（重複兩份） | 需要，但有兩份 |
| 6.9 MB | lxml | 是 |

**為何 PCMan／PTT Star 可小於 30 MB**：它們是原生 Windows 程式，直接用系統內建的視窗與網路元件（PTT Star 設定有 WinInet／WinHttp 選項，推測為原生；PCMan 為原生），沒有帶直譯器與 Qt。我們是 Python 加 Qt 整包，Qt 本身最小約 25 MB。

| 做法 | 預估大小 | 風險 |
|---|---|---|
| 現況 | 約 56 MB | — |
| 剔除用不到的 Qt 元件（OpenGL、Quick、Qml、Pdf 等） | 約 40 MB | 低；剔除後以打包版 selftest 驗證 |
| 再精簡 Qt 外掛與圖示檔 | 約 36 至 38 MB | 低到中 |
| UPX 壓縮 | 約 22 至 28 MB | 防毒常誤報，**不採用** |
| 改 .NET／C++／Rust 重寫 | 數 MB 至 70 MB | 等於新專案，不建議 |

**對外發佈（體積之外更重要的事）**
1. 防毒誤報：改發**資料夾版（onedir）**比壓縮體積更能降低誤報，啟動也快 1 至 3 秒。
2. 下載大小：資料夾版加 LZMA 安裝程式（Inno Setup）或 7z，**下載約 28 至 32 MB**（剔除 Qt 元件後），安裝後約 90 MB。
3. 授權：PySide6 為 LGPL，公開散布需附授權聲明並讓使用者可替換 Qt 函式庫（資料夾版較易符合）；專案本身尚無 LICENSE，需補第三方授權聲明（Qt、requests、BeautifulSoup、lxml 等）與使用者版 README。
4. 簽章：暫無；README 說明 SmartScreen 警告。
5. 之後加入的多分頁、站台管理、滑鼠、複製貼上、主題等純 Python 功能幾乎不增加大小；SSH 視做法而定（見第五節）。

## 七、廣告與贊助

- 不採第三方廣告：需 QtWebEngine（約 +200 MB）、載入第三方追蹤；使用者會在程式中輸入 PTT 帳密，信任成本高；遠端橫幅需新增對外連線，與「只連 PTT 與使用者貼的網址」的隱私承諾衝突；擷取新聞再營利會放大著作權與站規風險；桌面小工具收益通常有限。
- **決定：暫時用贊助方式。**
  - 設定頁「贊助作者」區塊，按鈕用預設瀏覽器開啟贊助連結（僅 http／https）。
  - 連結寫在 `src/version.py` 常數，沒設定連結時整個區塊不顯示。
  - 附說明：贊助出於自願、不影響功能、程式不追蹤也不上傳資料。
  - 程式本身不連贊助網站，點擊才開瀏覽器，隱私說明不用改。
  - 約 0.3 萬 token；**待使用者提供贊助連結與顯示文字**，未提供則先做區塊、連結留空。
- 若日後改要廣告：只用自簽的靜態橫幅、打包在程式內不連網抓取、放設定／關於頁、可關閉。
