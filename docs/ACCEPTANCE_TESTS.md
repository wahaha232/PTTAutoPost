## 0. 約定

### 0.1 層級

| 代號 | 層級 | 說明 |
|------|------|------|
| U | 單元 | 純邏輯，無網路、無桌面（屬性測試使用 hypothesis） |
| F | 夾具／語料（離線） | 對 TEST_CORPUS 的快照與合成夾具；**完全不連網**；結果可重複 |
| I | 整合 | 多元件＋暫存資料庫／本機 HTTP 夾具伺服器 |
| UI | 互動式 | 需 Windows 桌面工作階段 |
| P | PoC／假終端機 | 本機假終端機＋假 BBS；**不連真實 PTT** |
| M | 人工 | 使用者本人操作（含真實 PTT 測試看板）；**不發文** |
| L | 線上抽查 | 對真實網站 GET；預警用，**不入閘門** |

### 0.2 欄位
`ID`｜案例（Given／When／Then 精簡）｜層級｜里程碑／階段｜對應 FR／來源。**預期結果**直接寫在案例中。

### 0.3 通則（適用所有案例）
1. 測試**不得**連線 PTT、不得登入、不得發文（SP-08）。
2. 離線測試於「網路停用」環境也必須通過。
3. 解析類案例同一輸入執行兩次，輸出必須逐位元相同（決定性）。
4. 失敗案例必須驗證「錯誤碼＋使用者訊息＋日誌（含遮蔽）＋狀態」皆正確，而不只是「有報錯」。
5. 「成功」的定義一律包含內文完整性：**取得標題 ≠ 成功**（FR-110）。

## 2. AT-M1 — Milestone 1 端到端與閘門

### 2.1 端到端流程（每個 Tier A 來源 × 每篇快照；參數化）

**測試方法**：以本機 HTTP 夾具伺服器提供快照（不連真實網站）；以 UI 自動化或服務層驅動完整流程。

| ID | 案例 | 層 | 階段 |
|----|------|----|------|
| M1-001 | **完整流程**：貼 URL → 解析 → 欄位表顯示（值／狀態／來源策略）→ 修改一個欄位（狀態變「使用者修改」）→ 輸入個人心得 → 選模板 → 產生草稿 → 預覽 → 檢查 → 儲存草稿 → 重開草稿 → 確認 → **複製整篇** → 剪貼簿內容＝預覽 | UI | 4 |
| M1-002 | 同上，但**重啟程式後**草稿、欄位狀態、心得完整還原 | UI | 4 |
| M1-003 | 預覽＝複製＝確認雜湊輸入：三者逐位元組相等；複製標題／內文／整篇各自驗證 | I | 4 |
| M1-004 | 全程無任何自動送出：流程中剪貼簿之外的「外部效果」為零（無網路連線到 PTT、無按鍵注入、無視窗操作） | I | 4 |

### 2.2 全文而非標題（黃金比對）

| ID | 案例 | 層 | 階段 |
|----|------|----|------|
| M1-010 | 每個 Tier A 來源的 **`VERIFIED` 保留快照黃金檔**：解析內文依 GOLDEN_SPEC §5 比對——`S ≥ 95%`、`R ≥ 95%`、結構性防護 G1～G6 全過；`D ≤ 3%` 為 PASS，超過為 PASS_REVIEW（須人工檢視並記錄）；**門檻須為校準凍結後的 `metrics_v1`**；比對報告列出漏掉與多出的段落 | F | 3c |
