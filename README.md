# PTT AutoPost

Windows 桌面程式（Python + PySide6）：從新聞網址擷取文章、整理成 PTT 發文格式、預覽檢查、一鍵複製，並可把標題／內文**輸入到已登入的 PTT 終端機**。**發文的最後一步永遠由您自己按。**

## 啟動

```
pip install -r requirements.txt   # 第一次：安裝相依套件（Python 3.12）
python main.py                  # 開啟程式
dist\PTTAutoPost-<版本>-portable\PTTAutoPost.exe   # 可攜資料夾版（Qt 在 _internal\；config\ logs\ data\ 與 exe 同層）；版本紀錄見 src/version.py 的 CHANGELOG
PTTAutoPost.exe --selftest      # 無視窗自我檢測
PTTAutoPost.exe --probe         # 唯讀檢查 wss://ws.ptt.cc/bbs（連線、看到登入提示後斷線，不送出任何資料）
```
重新打包：`make_portable.bat`（`tools\make_portable.py`：onedir build → 組裝 → 驗證）；單檔診斷版：加 `--onefile`（預設仍是資料夾版）；下載壓縮：`python -X utf8 tools\make_portable.py --archive`（有 7-Zip 時為 LZMA2 7z，否則自動改產 ZIP）；安裝程式：`python -X utf8 tools\make_portable.py --installer`（需先安裝 Inno Setup 6，腳本為 `tools\PTTAutoPost.iss`）。測試：`python -m pytest`。可重現建置環境記錄於 `constraints-build.txt`（Python 3.12.10、PySide6 6.11.2、PyInstaller 6.22.2 等）。

## 功能

- **終端機與文章同頁**：左側終端機、右側文章面板（`QSplitter` 可拖曳）；文章面板有「擷取與欄位」「預覽與輸入」子分頁，可用按鈕或 `F12` 收合，寬度與收合狀態會記住；螢幕高度 ≤ 800 px 時預設收合。開啟草稿會自動展開面板並切到預覽。
- **終端機**：預設以 `wss://ws.ptt.cc/bbs` 直連 PTT（Big5＋ANSI，80×24），也可切換到站台書籤中的 `telnet://` 站台（明文，請注意風險）；可在上方欄位輸入帳號密碼登入（密碼只送出一次，不儲存、不寫入日誌），也可直接在終端機內自行輸入。重複登入詢問一律回答「n」，不會踢掉其他連線。連線中斷只會提示，不會自動重連或重送。
- **設定**：「設定」分頁可選擇介面字型與字級（套用到整個程式：選單、按鈕、分頁、文章面板與預覽；字級預設隨裝置／Windows 縮放自動調整，取消後可自訂 8–24 pt；終端機字型仍獨立）、終端機字型、字型大小、「填滿可視畫面」（80×24 畫面依視窗大小縮放），主題（淺色／深色／跟隨系統，預設跟隨系統）、終端機配色（永遠深色／跟隨主題，預設永遠深色），以及瀏覽器／圖片／上傳與更新設定；設定頁可捲動，長說明會換行；變更立即套用並存在本機（`data\pttpost.db`），可一鍵還原字型預設；也可按「套用」一次確認、儲存並顯示成功訊息。設定頁的「贊助作者」區塊與「說明 → 贊助 PTT AutoPost」會以預設瀏覽器開啟 Buy Me a Coffee 贊助頁（`https://www.buymeacoffee.com/wahaha232z`；`SPONSOR_URL` 留空或無效時整個區塊隱藏）；只有按下按鈕才會開啟連結，程式不追蹤也不上傳資料。
- **連線代理（跳板／VPN）**：設定頁可選擇 SOCKS5 或 HTTP 代理，只套用在 BBS 連線（WSS／Telnet）；連線前會驗證主機與連接埠，設定不完整時直接拒絕連線（不會悄悄改回直連）。PTT 會看到代理的對外 IP；文章擷取、更新、圖片下載與上傳仍直連。代理密碼只保留在記憶體，不寫入資料庫或日誌；狀態列只顯示代理端點，不顯示帳密。使用跳板可能違反 PTT 站規或觸發站方安全機制，請自行評估帳號風險；代理端看得到連線目標與時間。
- **超連結**：終端機畫面上的單列 http/https 網址會自動辨識（含中文雙格寬座標；被換行切斷的網址不猜、不接續）。偵測到的超連結一律加底線，滑鼠移上去會加粗、游標變手形；按下後原地放開才開啟，拖曳不會開啟，且點擊不會送出任何 BBS bytes。含帳密或其他 scheme 的網址一律拒絕。
- **瀏覽器與圖片**：設定頁可選系統瀏覽器、偵測到的 Chrome／Edge／Firefox，或自訂執行檔；外部瀏覽器以單一參數接收網址，不經 shell。圖片自動開啟（終端機，預設關閉，旁有 IP 隱私提醒）接受公開主機的 https 圖片：已知圖床，或 `.jpg／.jpeg／.png／.gif／.webp／.bmp／.avif` 副檔名；`.svg`、IP／localhost／內網主機不會自動開；同一連線同一網址只開一次、每次畫面最多 1 個、每分鐘最多 3 個，超過上限會提示一次。另有「滑鼠移到圖片連結時預覽」（預設關閉，停留約 0.5 秒在游標旁顯示小圖）與「文章內有圖片連結時直接顯示」（預設關閉，擷取後在程式內畫廊切換上一張／下一張）；兩者都不開外部瀏覽器。手動點擊仍可用。
- **站台書籤**：「站台」分頁內建 2026-10-23 實測可連的 13 個 BBS（PTT／PTT2 以 WSS，其餘 Telnet／SSH），可新增、修改、刪除、複製位址與做唯讀 TCP 測試。WSS／Telnet 可直接用內建終端機連線；SSH 目前只保存書籤。Telnet 是明文協定，請避免在公用網路輸入重要密碼。
- **更新／贊助**：設定頁或「說明 → 檢查更新…」會讀取 GitHub Releases，版本較新時可下載適合的檔案；攜帶版優先使用**增量更新檔**（只含變更檔案，約數 MB），下載並驗證 `update.json` 與每個檔案的 SHA-256 後，會**自動關閉程式、備份舊檔、覆蓋程式檔案並重新啟動**（Windows 無法覆蓋執行中的程式，所以一定要重新啟動；`config／logs／data` 不會被覆蓋）。沒有相符的增量檔時改下載完整 ZIP，同樣會自動套用（剝掉頂層資料夾，保留 `config／logs／data`）。完整 ZIP／安裝版 setup.exe 的下載走 HTTPS，GitHub 有提供 digest 時會驗證 SHA-256；setup.exe 不會自動執行，需自行安裝。0.8.10（含）以前的自動套用有問題，請手動換成 0.8.11 一次。打包版可在設定頁開啟「啟動時自動檢查更新」（背景查詢；沒更新或失敗時不打擾）。另有「強制更新」（重新下載目前／最新版）、「手動下載」（開 GitHub Releases）、下載進度條、「關於 PTT AutoPost」與「贊助 PTT AutoPost」選單。私人儲存庫可設 `PTTAUTOPOST_GITHUB_TOKEN` 環境變數（只用於 GitHub API；設定後改走 API 資產網址下載）。
- **更新簽章（0.8.19 起）**：每個更新檔都必須附上同名的 `.sig`（Ed25519 簽章，涵蓋檔名與 SHA-256），程式用內嵌於 `src/signing.py` 的公鑰驗證，沒有簽章、簽章不符或檔名版本與 Release 不一致時一律拒絕下載。發布時：`python tools\sign_release.py sign --key <私鑰檔> dist\PTTAutoPost-<版本>-portable.zip dist\PTTAutoPost-<版本>-delta-<舊版>.zip dist\PTTAutoPost-<版本>-setup.exe`，再把產生的 `.sig` 與更新檔一起上傳到 Release。私鑰不在儲存庫內（也可設 `PTTAUTOPOST_SIGNING_KEY` 指向它）；遺失私鑰後，已安裝的版本只能手動更新。套用更新途中失敗時，輔助腳本會用備份還原舊檔，下次啟動會顯示失敗原因；自動輸入或貼上進行中不會套用更新，會等結束後再詢問。
- **文章**：貼網址 → 背景擷取標題／媒體／網址／記者／時間／內文；每個欄位顯示「已取得／未取得／推定／已修改」；缺的欄位不補造；遇到登入牆、付費牆、403 只回報原因，不繞過；內文有「可能完整／疑似不完整／不足」判定（**抓到標題不代表抓到全文**）。可修改所有欄位；預覽可直接編輯；檢查標題／內文／Big5 編碼／控制字元／行寬；複製全文／內文／標題。「重新載入網頁」會用原文網址重新擷取並覆蓋欄位；PTT 文章請用終端機下方的「重新載入文章」（送出 Ctrl+L 讓 PTT 重繪目前畫面）。原文網址列另有「縮短網址」，可選 TinyURL／is.gd／v.gd／CleanURI，按下前會確認第三方隱私風險，且不自動縮短。「打包下載圖片（ZIP）」會先詢問 ZIP 儲存路徑，再把文章內圖片以原始網址（優先原始尺寸，非縮圖）下載成 `.zip`；文章內以純文字貼上的圖片網址也會納入，擷取到圖片時會自動勾選「文章內有圖片連結時直接顯示」並開啟畫廊。「預覽與輸入」頁包含個人心得、簽名檔（可直接輸入、儲存、勾選套用；按「重新產生預覽」時，非空白的簽名檔會自動附在貼文最下方，空值則不附加）與圖片上傳：可選 Catbox（永久）／Litterbox（72 小時）／uguu（3 小時）等不用註冊的公開圖床，上傳原始檔案並把網址插入內文游標處（上傳前會確認公開風險）。「回覆文章模式」勾選後只預覽／輸入回覆內容與簽名檔，標題自動顯示 `Re: 原標題`；請在 PTT 文章按 `r`、Enter 進入回覆編輯區，再按「輸入回覆內文」，程式只會把內容輸入在引文上方（不輸入標題、不存檔、不送出）。新文章可在目標看板文章列表按「開始發文（Ctrl+P）」開啟標題提示（只送 Ctrl+P），再依序「輸入標題」「輸入內文」。每次成功擷取都會視為新文章（保留已存草稿、清除上一篇的心得與確認狀態）；「清除全部欄位」可一次清空欄位、預覽與暫存狀態，不會刪除已儲存的草稿。
- **終端機選取、複製與貼上**：滑鼠左鍵拖曳可選取（以格為單位，中文雙格寬字元不會被切半；跨行時中間整列選取），按住 `Alt` 拖曳是矩形選取；雙擊選詞、三擊選整列；選取範圍以反轉前景／背景顯示。單擊、畫面被伺服器更新、或按下會送往 BBS 的按鍵時會清除選取；從連結上開始拖曳只會選取，不會開啟連結。`Ctrl+Shift+C` 或右鍵選單可複製（每行去掉行尾空白、以換行連接），右鍵另有「全選畫面」「複製整個畫面」；`Ctrl+C` 不含 Shift 仍送 `0x03`，複製不送任何 bytes。`Ctrl+Shift+V` 或右鍵「貼上」：離線或自動輸入／登入輔助進行中會拒絕並在狀態列說明；只接受 Big5（cp950）可編碼文字，無法編碼時列出字元並取消（不做部分貼上）；會移除 ESC／控制字元、`Tab` 轉 4 空白、換行轉 CR；超過 1 行或 200 字先顯示預覽確認，超過 5000 字直接拒絕；長文字依發文輸入的節奏分批送出，中途斷線或被鎖定會停止且不重送，並回報已送出多少。貼上進行中會暫停「輸入標題／內文」、登入與「前往看板」並在狀態列說明，結束後恢復；`Ctrl+V` 不含 Shift 仍送 `0x16`。
- **介面**：終端機底部只保留字型列與按鍵列；一般訊息顯示在狀態列，必要的儲存／輸入狀態錯誤會另開對話框；`F11` 切換全螢幕（「檢視」選單），`F12` 收合／展開文章面板；`Esc` 仍照常送進終端機；終端機配色可獨立選擇永遠深色或跟隨主題；文字欄位與內建的滑鼠右鍵選單（復原／剪下／複製／貼上／全選）為繁體中文。
- **草稿與簽名檔**：SQLite 存於 `data\pttpost.db`；草稿新增／開啟／搜尋／修改／刪除；最多 10 則簽名檔（下拉選擇）（編輯、儲存、每篇勾選套用）；開啟舊草稿後改選簽名檔會直接改用新選擇，不再被草稿快照鎖住。
- **輸入到 PTT**：只輸入文字。需先連線、已登入、勾選「我已確認」，畫面必須是「標題」提示或空白編輯區；**不按 Enter／Ctrl-X／存檔／送出**；畫面不符、斷線、逾時、取消都會停止，且同一草稿不會被重複輸入整篇。內文可選「快速貼上」或「賺 P 幣（逐字配速）」：後者每字約 0.5 秒，依 PTT「每字 0.25 P、每 2 秒最多 1 P」規則配速；畫面同時預估兩種模式的 P 幣（一般上限 1000 P、`[新聞]` 上限 5 P）與所需時間，實際仍以 PTT 為準。
